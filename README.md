# FUSIONest — Premium Interactive Construction Website

A premium interactive website for **FUSIONest Pvt. Ltd.** — Hyderabad's prefab and modular construction company.

## 🌐 Live Features

- **Cinematic Hero** — Three.js wireframe building animation on dark architectural background
- **Interactive Wall System** — 7 clickable wall layers (MS Frame → External Finish) with glass info panels
- **Construction Stages** — Drag-scrollable timeline with 8 on-site construction stages
- **Projects Gallery** — Filterable portfolio (Residential / Farmhouse / Resort / Commercial / Office)
- **Why Prefab** — Animated comparison vs traditional construction
- **Solutions** — Residential, Farmhouse, Hospitality, Commercial, Industrial
- **Models** — Nesthira, Modunite, Havasa, Fumora product series
- **Client Presentation Mode** — 10-slide fullscreen presentation with keyboard navigation
- **Admin Dashboard** — Add/edit/delete projects, upload images, view leads

## 🔧 Tech Stack

- Pure HTML5 + CSS3 + Vanilla JavaScript
- Three.js (wireframe 3D hero)
- Sora font (Google Fonts)
- localStorage for data persistence

## 📁 Structure

```
├── index.html        — Main website
├── admin.html        — Admin dashboard
├── css/style.css     — Full design system
├── js/main.js        — Core logic + Three.js
├── js/wall.js        — Interactive wall system
├── js/admin.js       — Admin CMS
└── assets/images/    — Project images
```
